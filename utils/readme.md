
## Installation

### Requirements

- Python 3.8+
- pandas
- streamlit
- plotly
- numpy

### Setup

```bash
# Install dependencies
pip install -r requirements.txt

# Run the dashboard
streamlit run test-app.py (original app)

# Process the new matches after adding impact players
run the preprocessing.py

# Test the new function in IPL impact player create the new preprocess file 
run preprocess-test-new-function.py

# Testing the new function called run forecasting for all series & impact player for IPL Copy for main file 16 Dec 2025
run new-function-testing.py
